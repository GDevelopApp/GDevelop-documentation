#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset:

![](rgb-effect.png)

Each color channel has its own X and Y offset (**Red X/Y**, **Green X/Y**, **Blue X/Y**), so you can control how far apart the colors are pulled and in which direction. Briefly increasing these offsets during the game (with the "Effect Parameter" action) is a common way to create a glitch or damage effect.
