#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset:

![](rgb-effect.png)

## Properties

Each color channel has its own X and Y offset (**Red X/Y offset**, **Green X/Y offset**, **Blue X/Y offset**), in pixels. Increasing these offsets pushes the corresponding color further away from the others, making the chromatic aberration more pronounced. This is often used for glitch effects or to convey damage/impact when applied briefly to a layer.
