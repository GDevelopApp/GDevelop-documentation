#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset. This is also known as *chromatic aberration* and is useful to simulate a glitch, a damage effect or an old-screen look:

![](rgb-effect.png)

Each color channel has its own X and Y offset (in pixels). The larger the offsets, the more the colors are separated. For a subtle lens-like aberration, keep the offsets small; animate them with events for a stronger glitch reaction (for example, when the player is hit).
