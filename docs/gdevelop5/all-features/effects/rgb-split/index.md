#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset:

![](rgb-effect.png)

This effect is also known as *chromatic aberration*. Each color channel has its own X and Y offset, so you can push the red, green and blue apart in different directions. Larger offsets create a stronger glitch or old-lens look, while small offsets give a subtle color fringe. Set every offset to `0` to disable the effect.
