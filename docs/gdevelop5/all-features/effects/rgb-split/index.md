#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset:

![](rgb-effect.png)

Each color channel has its own X and Y offset, so you can push the red, green and blue components in different directions to control the strength and angle of the split. A small offset gives a subtle chromatic aberration around the edges, while larger offsets create a strong glitch or damage effect. Animating the offsets from events lets you pulse the effect, for example when the player takes damage.
