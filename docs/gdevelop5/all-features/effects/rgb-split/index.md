#  RGB split effect

Separate each component's RGB(red, green, blue) colors and display them on the screen with an offset:

![](rgb-effect.png)

## Properties

Each color channel has its own **X offset** and **Y offset** (in pixels). Moving the red, green and blue channels apart creates the chromatic aberration look; setting all offsets to 0 removes the effect. Larger offsets make the color fringing more pronounced.
