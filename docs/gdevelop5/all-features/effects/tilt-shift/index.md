#  Tilt shift effect

Add blur to the top and bottom of the entire layer or object. Perfect to simulate a tiny world or a camera focus effect.

![](tilt-shift-effect.png)

The **Blur** parameter sets how strong the blur is at the top and bottom. The **Gradient blur** parameter controls the size of the sharp band in the middle: a smaller value keeps a thin strip in focus, while a larger value leaves more of the image sharp before it blurs out.
