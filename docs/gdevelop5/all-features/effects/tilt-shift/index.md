#  Tilt shift effect

Add blur to the top and bottom of the entire layer or object. Perfect to simulate a tiny world or a camera focus effect.

![](tilt-shift-effect.png)

The **Blur** property sets how strong the blur is in the blurred areas, and **Gradient blur** sets how gradually the image transitions from sharp (in the middle) to blurred (at the top and bottom). A large gradient value gives a smooth, wide focus band.

!!! note

    This effect only works on 2D layers and objects.
