#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

## Key properties

You can combine several settings to get the exact retro look you want:

- **Curvature** bends the image as if it was displayed on a rounded glass screen.
- **Line width** and **Line contrast** control the scanlines drawn over the image. Enable **Show vertical lines** to draw them vertically instead of horizontally.
- **Noise** and **Noise size** add static grain, while **Vignetting** darkens the corners of the screen.
- **Interlaced Lines Speed** animates the scanlines and **Noise Frequency** sets how often (per second) the static is refreshed. Set them to 0 to keep the effect completely still.

!!! note

    This effect only works on 2D layers and objects.
