#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

Several parameters let you dial in the retro look:

- **Line width** and **Line contrast** control the visible scanlines. Turn on **Show vertical lines** to add vertical scanlines too.
- **Curvature** bends the image like a curved tube screen (0 keeps it flat).
- **Noise** (and **Noise size**) add television static.
- **Vignetting** darkens the corners of the screen.
- **Interlaced Lines Speed** animates the scanlines. **Noise Frequency** sets how often the static refreshes (set either to 0 to stop the animation).
