#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

You can combine several settings to get the look you want: the scan *lines* (their width and contrast), screen *curvature* to bend the image like an old monitor, static *noise*, and *vignetting* to darken the edges of the screen. Enable **Show vertical lines** to get vertical scan lines instead of horizontal ones.

To animate the moving interlaced lines and the flickering noise, set **Interlaced Lines Speed** and **Noise Frequency** to a value greater than 0 (set them to 0 to keep a static, unanimated picture).
