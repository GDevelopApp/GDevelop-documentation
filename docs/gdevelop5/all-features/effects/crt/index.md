#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

The effect combines several looks that can be tuned independently:

- **Scanlines**: the *Line width* and *Line contrast* control the visible horizontal lines. Enable *Show vertical lines* to add a shadow-mask look.
- **Screen curvature**: the *Curvature* bends the image outwards to mimic a bulging CRT tube.
- **Vignetting**: darkens the edges of the screen for a more authentic tube look.
- **Noise**: adds animated static. The *Interlaced Lines Speed* and *Noise Frequency* animate the scanlines and static over time (set them to `0` to keep the effect completely static).
