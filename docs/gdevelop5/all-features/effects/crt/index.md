#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

This effect is often applied to a layer to give a whole scene a retro, arcade look.

## Properties

- **Curvature** bends the image to mimic the bulge of a real CRT screen. Set it to 0 to keep the image flat.
- **Line width** and **Line contrast** control the horizontal scanlines. Enable **Show vertical lines** to add vertical lines as well.
- **Noise** and **Noise size** add analog static over the image, while **Noise frequency** sets how often (per second) the static is refreshed.
- **Vignetting**, **Vignetting alpha** and **Vignetting blur** darken the corners of the screen.
- **Interlaced lines speed** animates the scanlines. Set it to 0 to keep them static, or increase it to make them scroll faster.
