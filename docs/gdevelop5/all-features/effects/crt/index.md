#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

## Properties

- **Line width** and **Line contrast** control the visible scanlines. **Show vertical lines** switches them from horizontal to vertical.
- **Curvature** bends the image outward to mimic a curved screen.
- **Noise** and **Noise size** add static grain. **Noise frequency** sets how many times per second the grain is refreshed (0 to keep it static).
- **Vignetting**, **Vignetting alpha** and **Vignetting blur** darken the edges of the screen.
- **Interlaced lines speed** animates the moving scanlines (0 to pause, 1 for normal speed, 2 for double speed, etc.).
