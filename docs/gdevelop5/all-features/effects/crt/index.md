#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

The effect combines several tweaks that you can enable or dial independently to build a retro look:

- **Curvature** bends the image outward like a rounded glass screen.
- **Line width** and **Line contrast** control the visible scanlines. Enable **Show vertical lines** to add vertical scanlines as well.
- **Noise** and **Noise size** add static grain, while **Noise frequency** sets how many times per second it is refreshed (set it to `0` for a frozen, still grain).
- **Vignetting** darkens the corners of the screen.
- **Interlaced lines speed** animates the scanlines: `0` pauses them, `1` is normal speed, `2` doubles it.
