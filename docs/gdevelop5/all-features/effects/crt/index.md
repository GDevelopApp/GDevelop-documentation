#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

## Parameters

- **Line width** and **Line contrast** control the scanlines that give the retro look, and **Interlaced Lines Speed** scrolls them over time (set it to 0 to keep them still).
- **Curvature** bends the image to mimic a curved screen.
- **Noise**, **Noise size** and **Noise Frequency** add the flickering static of an old signal.
- **Vignetting**, **Vignetting alpha** and **Vignetting blur** darken the corners of the screen.
- Enable **Show vertical lines** to add vertical scanlines in addition to the horizontal ones.
