#  CRT effect

Applies a CRT effect, simulating an old cathode-ray tube television.

![](crt-effect.png)

The look is built from several independent elements that you can mix and match:

- **Line width** and **Line contrast** control the horizontal scanlines (use *Show vertical lines* to turn them vertical instead).
- **Noise** and **Noise size** add the grainy static of an analog signal.
- **Curvature** bulges the image outward like a curved glass screen.
- **Vignetting**, **Vignetting alpha** and **Vignetting blur** darken the corners.

The effect can animate on its own: **Interlaced lines speed** scrolls the scanlines over time (0 pauses the animation) and **Noise frequency** sets how many times per second the static is refreshed.

!!! note

    This effect only works on 2D objects and layers.
