#  Drop shadow effect

Add a drop shadow around your object, visible on the layer.

![](drop-shadow-effect.png)

## Key properties

- **Distance** and **Rotation** set how far the shadow is offset from the object and in which direction (an angle in degrees).
- **Blur** softens the edges of the shadow, and **Alpha** controls how opaque it is.
- **Color of the shadow** lets you tint the shadow (a colored glow rather than a plain dark shadow, for instance).
- **Shadow only** hides the object itself and keeps only its shadow, which is handy to render a separate shadow object placed on the ground.
