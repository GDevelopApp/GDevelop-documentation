#  Drop shadow effect

Add a drop shadow under your objects visible on the layer.

![](drop-shadow-effect.png)

## Parameters

- **Distance** and **Rotation**: control how far the shadow is offset from the image and in which direction (in degrees).
- **Blur** and **Quality**: soften the shadow's edges. A higher quality gives a smoother blur at the cost of performance.
- **Color** and **Alpha**: set the color and transparency of the shadow.
- **Shadow only**: when enabled, only the shadow is rendered and the original image is hidden. This is useful to render a separate, independently-colored shadow object.
