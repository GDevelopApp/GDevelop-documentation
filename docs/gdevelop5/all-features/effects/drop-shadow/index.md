#  Drop shadow effect

Add a drop shadow under your object's visible on the layer.

![](drop-shadow-effect.png)

The **Distance** and **Rotation** parameters set how far the shadow is offset and in which direction, so you can place the shadow to match a light source. **Blur** softens the shadow's edges, while **Color** and **Alpha** set its tint and transparency. Enable **Shadow only** to hide the object itself and keep just its shadow, which is handy for casting a shadow onto the ground from a separate object.
