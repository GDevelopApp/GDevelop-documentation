#  Drop shadow effect

Add a drop shadow under your object's visible on the layer.

![](drop-shadow-effect.png)

The position of the shadow is set with **Distance** (how far it is offset from the object) and **Rotation** (the direction of the offset, in degrees). **Blur** softens the shadow's edge, while **Color** and **Alpha** set its tint and opacity.

Enable **Shadow only** to hide the object itself and keep only its shadow — useful to render a separate silhouette, for example on the ground.

!!! note

    This effect only works on 2D objects and layers.
