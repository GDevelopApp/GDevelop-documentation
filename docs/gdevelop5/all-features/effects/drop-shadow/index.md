#  Drop shadow effect

Add a drop shadow under your object's visible on the layer.

![](drop-shadow-effect.png)

Use **Distance** and **Rotation** to control how far the shadow is offset from the object and in which direction, **Blur** for how soft its edges are, and **Alpha** and **Color** for its opacity and tint. Enable **Shadow only** to hide the object itself and render just the shadow, which is useful for casting a separate shadow object on the ground.
