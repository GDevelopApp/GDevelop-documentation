#  Drop shadow effect

Add a drop shadow under your object's visible on the layer.

![](drop-shadow-effect.png)

## Properties

- **Distance** and **Rotation** set how far the shadow is offset and in which direction, simulating the position of the light source.
- **Blur** softens the shadow's edges and **Quality** controls how smooth that blur looks (higher values cost more performance).
- **Color** and **Alpha** set the shadow's tint and opacity.
- **Shadow only** hides the original image and keeps only the shadow, which is useful to build a separate shadow object.
