#  God rays effect

Cast rays of light from the top of the screen. **This won't work well if shown on top of the background color of the scene**. Be sure to use an object acting as a background or a floor.

![](godray-effect.gif)

The direction and position of the rays are set with the **Angle** and the **Center X**/**Center Y** properties, so you can make the light come from a sun or a window placed anywhere on screen. The **Gain** and **Light** properties control how strong and how long the rays are, while **Lacunarity** changes how detailed they look. The rays animate automatically; use **Animation speed** to make them move faster, slower, or set it to `0` to freeze them.
