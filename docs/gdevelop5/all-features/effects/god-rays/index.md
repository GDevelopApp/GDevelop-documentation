#  God rays effect

Cast rays of light from the top of the screen. **This won't work well if shown on top of the background color of the scene**. Be sure to use an object acting as a background or a floor.

![](godray-effect.gif)

## Properties

- **Parallel** makes all rays point in the same direction (as from a distant sun). When disabled, the rays spread out from the **Center X**/**Center Y** point, as from a nearby light source.
- **Angle** tilts the direction the rays come from, and **Light** adjusts how far the light reaches.
- **Gain** and **Lacunarity** shape the intensity and detail of the rays.
- **Animation speed** continuously animates the rays (0 to pause, 1 for normal speed).
