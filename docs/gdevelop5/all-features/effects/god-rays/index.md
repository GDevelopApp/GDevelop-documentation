#  God rays effect

Cast rays of light from the top of the screen. **This won't work well if shown on top of the background color of the scene**. Be sure to use an object acting as a background or a floor.

![](godray-effect.gif)

Use **Angle** to tilt the direction the rays point, and **Gain** and **Light** to control their brightness and length. Set **Animation Speed** above 0 to make the rays shimmer and move over time (0 keeps them static). When **Parallel** is enabled the rays are all cast in the same direction (like distant sunlight); disable it to make the rays spread out from the **Center X / Center Y** point instead, for a nearby light source.
