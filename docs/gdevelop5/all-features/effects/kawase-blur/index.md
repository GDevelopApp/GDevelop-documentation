#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

The **Blur** setting controls the overall strength, while **Quality** increases the number of blur passes for a smoother result (at the cost of performance). Use **Pixelize X** and **Pixelize Y** to blur more along one axis than the other, for example to create a horizontal or vertical motion-like blur.
