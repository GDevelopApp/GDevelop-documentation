#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

## Properties

- **Blur** sets the strength of the blur and **Quality** controls how smooth it looks (higher values are smoother but cost more performance).
- **Pixelize X** and **Pixelize Y** can stretch the blur more on one axis, for example to create a horizontal or vertical motion-like blur.
