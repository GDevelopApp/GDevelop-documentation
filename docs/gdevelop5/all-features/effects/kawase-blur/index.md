#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

The **Pixelize X** and **Pixelize Y** properties let you spread the blur in a blocky way, which is handy to keep a pixel-art or retro look while blurring.

!!! tip

    When used on an object, a strong blur can be cut off at the edges of the object. Increase the **Padding** property to add some extra space around the object so the blur is fully visible.
