#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

Increase the **Blur** parameter for a stronger blur. **Quality** controls how smooth the blur looks: higher values give a cleaner result but are more costly to render. The **Pixelize X**/**Pixelize Y** parameters can stretch the blur more on one axis than the other.

!!! tip

    Changing the **Blur** parameter during the game (with the "Effect Parameter" action) is a simple way to create a focus/unfocus transition, for example to blur the background when a menu opens.
