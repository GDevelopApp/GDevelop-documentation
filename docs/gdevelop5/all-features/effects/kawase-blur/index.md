#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

The **blur** parameter sets the blur strength and **quality** how many passes are used (a higher quality is smoother but more demanding). The **Pixelize X** and **Pixelize Y** parameters bias the blur horizontally or vertically, which can be used to fake a directional motion blur. Animating the blur [through events](/gdevelop5/objects/effects) is a common way to blur the background when a pause menu or dialog opens.
