#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

**Blur** sets the strength of the blur, and **Quality** sets how many passes are used (higher values give a smoother result but cost more performance). **Pixelize X** and **Pixelize Y** can stretch the blur more on one axis than the other, letting you create a directional (motion-like) blur.

!!! note

    This effect only works on 2D objects and layers.
