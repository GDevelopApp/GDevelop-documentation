#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

## Properties

- **Blur** sets the strength of the blur.
- Higher **Quality** produces a smoother result but is more demanding on performance.
- **Pixelize X** and **Pixelize Y** can be increased to blur more along a single axis (for example, a horizontal-only motion blur).
