#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

The **Pixelize X** and **Pixelize Y** properties let you blur more on one axis than the other, which is handy for a directional (motion-like) blur. Increasing the **Quality** gives a smoother result at the cost of some performance.
