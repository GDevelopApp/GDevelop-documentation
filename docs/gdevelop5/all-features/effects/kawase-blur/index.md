#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

## Key properties

- **Blur** sets the strength of the blur, and **Quality** sets how many passes are used to smooth it (higher values look smoother but cost more performance).
- **Pixelize X** and **Pixelize Y** stretch the blur along an axis, which lets you create a directional (horizontal or vertical) blur.

!!! note

    This effect only works on 2D layers and objects.
