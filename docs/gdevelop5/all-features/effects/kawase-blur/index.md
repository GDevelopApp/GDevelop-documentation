#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

## Parameters

- **Blur**: the strength of the blur.
- **Quality**: the number of blur passes. A higher quality gives a smoother result but is more demanding.
- **Pixelize X/Y**: stretch the blur horizontally or vertically. Keep both at `1` for a uniform blur, or increase one axis for a directional, streaky blur.
