#  Kawase blur effect

This is a faster version of the traditional "Blur" effect. It's recommended that you use this one rather than the "Gaussian" blur effect.

## Parameters

- **Blur** sets the strength of the blur, and **Quality** controls how smooth the result looks (higher values cost more performance).
- **Pixelize X** and **Pixelize Y** stretch the blur horizontally or vertically, which can be used to create a directional (motion-like) blur.
