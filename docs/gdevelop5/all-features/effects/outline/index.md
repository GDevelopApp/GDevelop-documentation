#  Outline

Draws an outline around the rendered image. This is commonly added to a single **object** to highlight it (for example, an item that can be picked up or the currently selected unit), but it can also be added to a whole layer.

When added to a layer, **this won't work well if shown on top of the background color of the scene**. Be sure to use an object acting as a background or a floor.

![](outline-effect.png)

!!! tip

    When used on an object, a thick outline can be cut off at the edges of the object. Increase the **Padding** property to add some extra space around the object so the outline is fully visible.
